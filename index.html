🚀 Publication sur Google Play Store & Apple App Store

Cette application est configurée avec Capacitor et PWA :

# 1. Installer Capacitor
npm install @capacitor/core @capacitor/cli
npm install @capacitor/android @capacitor/ios

# 2. Générer l'application Android & iOS
npx cap add android
npx cap add ios
npx cap sync

# 3. Ouvrir dans Android Studio / Xcode
npx cap open android
npx cap open ios
